Vérifications rapides

  • Boot Order : vérifier l’ordre de démarrage (USB/SSD/HDD).
  • Secure Boot : peut bloquer certains Live USB non signés.
  • CSM / Legacy : à activer uniquement si nécessaire pour vieux supports.
  • UEFI vs Legacy : privilégier UEFI si Windows 10/11 installé en UEFI.

Astuce — si le PC démarre trop vite, utiliser WinRE ou redémarrer en maintenant Shift + Redémarrer pour accéder aux options avancées.
